# 《蜕》MOLT —— 第一章 · 搁浅（可玩概念原型）

> 一场感知移民。不是"你去外星冒险"的游戏，而是"你学会不再是人类"的游戏。

你的意识被托付给潮汐星球**洄**上的一具原生宿主躯体。这个物种没有长在头上的眼睛——
它通过**把注意力注入别的事物**来感知世界。本章教会你放下第一个人类拐杖：
长在自己头上的镜头。

## 怎么玩

直接用浏览器打开 `index.html` 即可（无任何外部依赖，画面与音乐全部程序化生成，建议佩戴耳机）。

| 操作 | 按键 |
|---|---|
| 行走 | `←` `→` 或 `A` `D` |
| 注入注意力 | **点击**发光之物（视点与光随之而去） |
| 人类之眼（临时拐杖） | `空格` |
| 动词囊 | `V` |
| 声音开关 / 暂停 | `M` / `Esc` |

## 本章体验内容（约 15–25 分钟）

- **注意力即镜头**：从潮池、行者、孢子、灯塔水母的位置看世界——包括看你自己
- **语素贝壳 ×5**：只有借来的眼睛才看得见的收集物
- **海葵门**：一道讨厌"被走近的目光"的门——别用自己看它
- **暗礁湾**：从高处的水母俯瞰，遥控自己的躯体踏石而过
- **营地**：前蜕者、动词囊、嫁接演示，以及那一格不是你点亮的「归」
- **暗潮洞**：人类之眼在此会灼伤宿主
- **初壳蜕落**：归还借来的眼睛，接住你的第一个动词——「落」

## 设计支柱（完整设计见对话记录）

五次蜕壳 = 五个被替换的人类习惯：视觉（注意力即镜头）→ 动作（余波操控）→
思维与语言（世界没有名词）→ 空间（距离即关系）→ 自我（复数的我）。
本原型实现第一根支柱；第二章《借落》将开启动词嫁接沙盒。
